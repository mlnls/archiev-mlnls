## 종이로도 나눠 준다

성적 리포트는 화면으로만 보는 게 아니라 종이로 뽑아서 나눠 주기도 했다.
화면에서 멀쩡한 차트가 인쇄하면 배율이 틀어지거나 잘렸다.

## 인쇄는 화면과 다른 매체다

브라우저는 인쇄할 때 페이지를 새로 배치한다. 화면을 그대로 찍는 게 아니다.

- 폭이 바뀐다. A4에서 여백 10mm를 빼면 인쇄 폭은 190mm, 약 718px이다. 화면보다 좁다
- 쪽이 나뉜다. 긴 화면은 아무 데서나 잘려 다음 쪽으로 넘어간다
- 배경색이 빠진다. 브라우저는 잉크를 아끼려고 배경을 기본으로 인쇄하지 않는다

차트가 잘린 건 첫 번째 때문이었다.
차트는 들어 있는 상자의 폭을 재서 그 크기로 그린다. 인쇄 폭이 좁아지면 넘치는 부분이 잘린다.

## 인쇄용 규칙을 따로

`@media print`에 인쇄용 규칙을 따로 두었다.

![화면의 리포트가 window.print로 A4 쪽마다 나뉘고, 분량이 많은 쪽은 더 줄여 담는 모습](print.svg "화면 한 장이 A4 여러 쪽으로")

```text src/index.css (줄여서 옮김)
@media print {
  * { print-color-adjust: exact; }          /* 배경색 · 차트 색을 그대로 */
  @page { size: A4; margin: 10mm; }

  html, body { zoom: 0.95; }               /* 전체를 살짝 줄여 폭에 맞춘다 */
  .print-page { break-after: page; }       /* 덩어리마다 새 쪽에서 시작 */
  .print-page.more-scope { zoom: 0.75; }   /* 분량이 많은 덩어리는 더 줄인다 */
  .hide-on-print { display: none; }        /* 출력 버튼 같은 건 숨긴다 */
}
```

쪽이 아무 데서나 잘리지 않게, 한 쪽에 들어갈 덩어리를 `.print-page`로 묶었다.
그리고 덩어리마다 다음 쪽에서 시작하게 했다.
덩어리에 따라 분량이 달라서, 많은 쪽은 `zoom`을 한 번 더 줄였다.

차트도 잘리던 부분을 하나씩 손봤다.

## 출시 전 남은 QA

배치고사 서비스는 출시를 앞두고 QA 항목이 남아 있었다.
QA 항목에는 번호가 붙어 있었다.

## 번호마다 커밋 하나

남은 항목을 번호 순서대로 하나씩 고쳤다.
커밋 메시지에 QA 번호를 남겨서, 어느 항목을 어떤 수정으로 닫았는지 바로 찾을 수 있게 했다.

```text git log
QA: 205 QA 수정
QA: 206 QA 수정
QA: 207 QA 수정
QA: 208 QA 수정
```

다시 열린 항목은 "재수정"으로 같은 번호에 커밋을 이어 붙였다.
하드코딩된 연도처럼 매년 다시 깨질 곳은 동적으로 바꿨다.
