메인 조회 API에 ISR

메인 화면의 조회 API 응답을 5분마다 다시 만들어 피크와 비용을 같이 잡았습니다.

5분ISR 재검증

  1. 01한 달에 하루 몰리는 트래픽
  2. 02콘솔 수작업 대신 yaml
  3. 03언제든 되돌릴 수 있는 전환
  4. 04메인 조회 API에 ISR
  5. 05IP 차단이 서버 자신을 막았다

문제

  • 메인 화면은 접속할 때마다 같은 조회 API를 불렀다.

해결

  • 메인 조회 API에 5분 주기 ISR을 적용했다.

결과

  • 피크 대응과 평상시 비용 절감을 같이 얻었다.
