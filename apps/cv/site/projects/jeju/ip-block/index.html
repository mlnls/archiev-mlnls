IP 차단을 켰더니 서비스가 내려갔다

IP 차단을 도입했다.
그런데 도입한 뒤 서비스가 다운됐다. 차단된 IP가 Next 서버 자신이었다.

원인

백엔드가 보기에는 모든 요청이 Next 서버에서 왔다.
SSR에서는 사용자의 브라우저가 아니라 Next 서버가 API를 부르기 때문이다.
그래서 차단 규칙에 걸린 것도 사용자가 아니라 Next 서버의 IP였다.

실제 사용자 IP 넘기기

Next 서버가 API를 부를 때 실제 사용자 IP를 x-forwarded-for로 넘기게 했다.

결과

이제 실제 사용자 IP 기준으로 차단된다.
