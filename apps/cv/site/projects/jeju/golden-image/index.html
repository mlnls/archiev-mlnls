콘솔 수작업 대신 yaml

제주이어드림 · 2/5 · yaml (콘솔 수작업 대신)

코드를 AMI로 굳히고, 인프라 전체를 템플릿 하나로 만들어 실패하면 통째로 되돌립니다.

문제

  • 콘솔에서 손으로 만든 인프라는 다시 만들 수도, 되돌릴 수도 없다.

해결

  • Git 브랜치를 빌드해 AMI(Golden Image)로 굳히고, 환경 스택에서는 AMI ID만 바꿔 Launch Template과 ASG를 만든다.
  • VPC · 보안 그룹 · ASG · ALB를 CloudFormation 템플릿 하나로 만든다.

결과

  • 하나라도 잘못되면 스택 전체가 되돌아간다.
