문제

  • S3 + CloudFront 정적 호스팅에는 사양을 바꿀 옵션이 없었고, 공고 날에는 프론트와 백엔드 서버가 함께 멈췄습니다.
  • 필요한 건 한 달에 하루 몰릴 때만 자동으로 늘어나는 구조였습니다.

한 일

Golden Image
Git 브랜치를 빌드해 AMI로 굳히고, 환경 스택에서는 AMI ID만 바꿔 Launch Template과 ASG를 만듭니다.
한 번에, 실패하면 롤백
VPC · 보안 그룹 · ASG · ALB를 템플릿 하나로 만들고, 하나라도 잘못되면 스택 전체가 되돌아갑니다.
안전한 전환
새 리스너 규칙을 우선순위 509 · 510 뒤에 두고 확인한 다음 수동으로 전환해, 언제든 바로 되돌릴 수 있게 했습니다.
Step Scaling
타깃당 요청 3,000 / 6,000을 기준으로 1 → 2 → 3대로 늘어납니다.
장애 해결
IP 차단 로직이 Next 서버 자체를 막아 생긴 장애를 x-forwarded-for 전달로 해결했습니다.

결과

  • 한 달에 하루 몰리는 트래픽을 위해, 필요할 때만 늘어나는 프론트 서버를 만들었습니다.
