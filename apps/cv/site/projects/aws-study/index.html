AWS SAA-C03 스터디 사이트

스터디장으로 운영하는 AWS 자격증 스터디를 위해, 정적 사이트를 그대로 두고 Postgres 함수를 API로 써서 로그인 · 이어 풀기 · 랭킹 · 오답 리뷰를 만들었습니다.

문제

  • index.html 하나에 localStorage로 기록하던 사이트라, 폰과 노트북을 오가며 이어 풀 수도, 누가 무엇을 골라 틀렸는지 같이 볼 수도 없었습니다.
  • 서버를 따로 두기는 무거웠고, 필요한 건 DB뿐이었습니다.

한 일

RLS on · 정책 없음
테이블은 공개 키로 한 줄도 읽을 수 없게 막고, security definer 함수만 열었습니다. 첫 인자 token으로 사용자와 관리자를 확인합니다.
SDK 없이
fetch 하나로 함수를 부르고, 설정이 비어 있으면 localStorage로 돌아가게 했습니다.
PIN 로그인
pgcrypto bcrypt로 PIN을 비교하고, 실패 횟수가 롤백되지 않게 예외 대신 JSON을 돌려줍니다.
이어 풀기 충돌
오래된 화면이 최신 기록을 덮어쓰던 문제를 세션 소유권(sid)으로 막고, 밀려나면 최신을 불러오거나 여기서 이어 가게 했습니다.
스터디 기능
실전 모의고사별 오답 노트, 분류별 성적, 29일 학습 교재, 관리자용 사람별 오답 · 문제별 선택지 분포를 만들었습니다.

결과

  • 서버 없이 로그인 · 이어 풀기 · 랭킹 · 오답 리뷰까지 만들어, 스터디원 4명이 모의고사를 같이 풀고 제출 뒤 오답을 함께 리뷰합니다.

배운 것

  • 예외는 실패 카운터까지 롤백합니다. 남겨야 할 기록은 예외 대신 값으로 돌려줘야 합니다.
  • “없으면 올린다”는 위험합니다. 지운 일시정지가 옛 캐시에서 되살아나 서버를 기준으로 바꿨습니다.
  • 공개 키는 공개해도 됩니다. 그 키로 할 수 있는 일이 정해진 함수뿐이게 설계하면요.
