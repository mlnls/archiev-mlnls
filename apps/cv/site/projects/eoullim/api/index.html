사용자 · 관리자 실 API 연동

어울림 · 3/5 · 전 도메인 (콘텐츠 · 계정 · 신고 · 통계)

한 모노레포에서 두 앱을 함께 만들고, 게시글부터 관리자 통계까지 실 API에 붙였습니다.

문제

  • 연동할 범위가 게시글 · 댓글부터 신고 · 관리자 통계까지 넓었다.

해결

  • 사내 CLI로 만든 Turborepo 모노레포에서 사용자 사이트와 관리자를 함께 개발했다.
  • 사용자는 fetch, 관리자는 axios 위에 공통 HTTP 계층을 두었다.

결과

  • 게시글 · 댓글 · 한마디 · 검색 · 알림 · 신고와 관리자 통계까지 실 API에 연동했다.
