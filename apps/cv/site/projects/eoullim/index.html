벽촌 · 2026.10 – 현재 · withlim.kr · 관리자

동작구 주민과 구의원이 함께 이야기하는 지역 커뮤니티의 사용자 사이트와 관리자를 개발했습니다.

역할: 사용자 · 관리자 프론트엔드 전체
기술: Next.js, Turborepo, Tailwind CSS, TipTap, Lightsail

  1. 1.
    시안이 바뀌는 동안 같이 개발하기 v0.2 → v0.5 · 디자인 토큰

    화면이 디자인 토큰만 보게 해, 토큰이 바뀌면 화면 전체가 한 번에 따라가게 했습니다.

  2. 2.
    어느 시안을 반영했는지 커밋으로 17번 · 2주 동안 시안 반영

    커밋에 Figma 노드 ID를 남겨 시안 반영 이력을 커밋만 보고 알 수 있게 했습니다.

  3. 3.
    사용자 · 관리자 실 API 연동 전 도메인 · 콘텐츠 · 계정 · 신고 · 통계

    한 모노레포에서 두 앱을 함께 만들고, 게시글부터 관리자 통계까지 실 API에 붙였습니다.

  4. 4.
    에디터 문서와 화면 블록 TipTap · 변환 계층

    TipTap 문서와 화면에 그리는 블록을 서로 바꾸는 변환 계층을 만들었습니다.

  5. 5.
    설치와 로그인 PWA · 설치 · 로그인

    PWA 설치 안내, 휴대폰 번호 로그인, 로그인 뒤 보던 화면으로 돌아가는 흐름을 만들었습니다.
