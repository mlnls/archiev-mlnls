한 일

토큰만 보는 화면
색 · 글꼴 · 그림자를 토큰으로만 쓰게 해, 토큰 export를 바꾸면 화면 전체가 한 번에 바뀌게 했습니다.
시안 추적
커밋에 Figma 노드 ID를 남겨 어느 시안을 반영했는지 커밋만 보고 알 수 있게 했습니다.
모노레포
사내 CLI로 만든 Turborepo 모노레포에서 사용자 사이트와 관리자를 함께 개발합니다.
실 API 연동
사용자는 fetch, 관리자는 axios로 공통 HTTP 계층을 두고 게시글 · 댓글 · 한마디 · 검색 · 알림 · 신고와 관리자 통계까지 연동했습니다.
에디터
TipTap 문서와 화면 블록을 서로 바꾸는 변환 계층을 만들었습니다.
설치와 로그인
PWA 설치 안내, 휴대폰 번호 로그인, 로그인 뒤 보려던 화면으로 돌아가는 흐름을 만들었습니다.

결과

  • 2주 동안 17번 바뀐 시안을 토큰째로 따라가며 사용자 사이트와 관리자를 함께 열었습니다.
