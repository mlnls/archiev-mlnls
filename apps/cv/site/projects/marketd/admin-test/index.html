하나 고치면 어디가 깨졌는지 몰랐다

넓고 자주 바뀌는 관리자 화면에 요구사항처럼 읽히는 통합 테스트를 깔았습니다.

935개관리자 테스트 케이스

  1. 01한쪽만 바꾸면 상대편이 깨졌다
  2. 02긴급 수정이 스토어 심사를 기다렸다
  3. 03하나 고치면 어디가 깨졌는지 몰랐다
  4. 04jsdom이 못 보는 곳만 브라우저로
  5. 05주소만 알면 누구나 보던 채팅 사진
  6. 0660초가 지나면 깨지는 이미지

문제

  • 관리자 화면은 회원 · 상품 · 결제 · 정산 · 통계 · 배달 · 고객센터까지 넓고 수정이 잦아, 고칠 때마다 손으로 확인해야 했다.

해결

  • MSW로 서버 대신 목업 API를 띄웠다.
  • 도메인별 fixture와 alert · table · download 공통 유틸을 만들었다.
  • 테스트 이름을 “~하면 ~한다” 문장으로 써서 요구사항처럼 읽히게 했다.

결과

  • 테스트 파일 84개 · 케이스 935개
  • 로컬 재실행 175/175가 약 10초에 통과

메모

  • zod는 모르는 필드를 에러 없이 지운다. 관리자 스키마에 새 필드를 넣지 않으면 조용히 사라진다.
