마켓:D

벽촌 · 2026.03 – 10 · m.dongjakmarket.co.kr

동네 가게의 마감 임박 상품을 거래하는 서비스에서 흩어진 레포를 모노레포로 합치고, 관리자 화면의 테스트 구조와 앱 채팅 이미지의 보안 구조를 맡았습니다.

역할: 모노레포 전환 · 관리자 테스트 (admin 전담) · 채팅 이미지 연동
기술: React Native (Expo), React, Turborepo, pnpm, TanStack Query, zod, Vitest, MSW, Playwright

  1. 1.
    한쪽만 바꾸면 상대편이 깨졌다 레포 3개 → 1개 · pnpm workspace

    관리자 · 앱 · 웹뷰 레포를 합치고 메시지 타입을 공통 패키지로 묶었습니다.

  2. 2.
    긴급 수정이 스토어 심사를 기다렸다 3갈래 · 배포 경로

    바뀐 것이 화면인지, 연결 로직인지, 바이너리인지에 따라 배포 길을 나눴습니다.

  3. 3.
    하나 고치면 어디가 깨졌는지 몰랐다 935개 · 관리자 테스트 케이스

    넓고 자주 바뀌는 관리자 화면에 요구사항처럼 읽히는 통합 테스트를 깔았습니다.

  4. 4.
    jsdom이 못 보는 곳만 브라우저로 5개 · E2E

    통합 테스트로 확인할 수 없는 지점만 골라 Playwright로 옮겼습니다.

  5. 5.
    주소만 알면 누구나 보던 채팅 사진 영구 → 60초 · 사진 주소 수명

    공개 버킷의 채팅 사진을 비공개 버킷과 60초 서명 URL로 옮겼습니다.

  6. 6.
    60초가 지나면 깨지는 이미지 key당 1번 · 재발급

    미리 갱신하지 않고, 깨진 이미지만 key당 한 번 다시 발급합니다.
