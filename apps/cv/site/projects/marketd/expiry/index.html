60초가 지나면 깨진다

서명 URL은 60초 뒤에 만료된다.
채팅방을 오래 띄워 두면 그 사이에 사진이 깨진다.

미리 갱신할까, 깨지면 고칠까

방법은 두 가지다.

  • 만료되기 전에 미리 새 URL을 받아 둔다
  • 깨지면 그때 새로 받는다

미리 받으면 화면에 보이지도 않는 사진까지 계속 재발급한다.
이미 화면에 그려진 이미지는 URL이 만료돼도 그대로 보인다. 다시 불러올 때만 문제가 된다.
그래서 깨졌을 때만 고치기로 했다.

깨진 것만, key당 한 번

이미지가 깨지면(onError) 그때 다시 발급받는다.
같은 key는 한 번만 재발급하고, 그래도 실패하면 깨진 이미지로 둔다. 무한히 다시 시도하지 않게.

여러 장이 동시에 깨질 수도 있다. 같은 시점에 받은 URL은 같은 시점에 만료되니까.
이때 요청이 장 수만큼 나가지 않게 refetch({ cancelRefetch: false })를 썼다.
이미 나가 있는 요청이 있으면 새로 보내지 않고 그걸 기다린다.

apps/mobile/hooks/useChatImageUrls.tsTypeScript
// 로드 실패 시 같은 key는 1번만 재발급하고, 그래도 실패하면 깨진 이미지로 둠
const onErrorImage = async (key: string) => {
  if (retriedKeysRef.current.has(key)) {
    markAsBroken(key);
    return;
  }
  retriedKeysRef.current.add(key);
  const { isError: isRefetchError } = await refetch({ cancelRefetch: false });
  if (isRefetchError) markAsBroken(key);
};

확대 보기는 예외

사진을 눌러 크게 볼 때는 새로 불러온다. 이때 만료된 URL이면 깨진 화면부터 보인다.
그래서 확대 보기 전에만 URL의 X-Amz-Date와 X-Amz-Expires로 만료를 계산해서, 지났으면 먼저 재발급한다.
