법률신문 한국법조인대관

벽촌 · 2025.09 – 현재 · lawpeople.lawtimes.co.kr

법조인 3만여 명을 검색하는 서비스의 렌더링 성능과 분석 데이터를 바로잡고, VPN 뒤에 있는 서버의 다섯 단계 손작업 배포를 머지 한 번으로 바꿨습니다.

역할: 렌더링 성능 · GA4 · 배포 파이프라인 · 보안
기술: Next.js, GA4, GitHub Actions self-hosted runner, Docker

  1. 1.
    SSR이 꺼져 있던 렌더링 80 → 99 · Lighthouse 성능

    화면 전체를 감싸던 클라이언트 렌더링을 필요한 곳으로 좁히고 폰트를 바꿨습니다.

  2. 2.
    페이지뷰가 빠지고 있었다 월 103만 건 · GA4 이벤트

    SPA 라우팅에서 누락되던 GA4 page_view를 라우트 이벤트 기준으로 다시 잡았습니다.

  3. 3.
    들어갈 수 없는 서버에 배포하기 5단계 → 머지 1번 · 사람이 하는 일

    VPN IP만 받는 EC2에, 베스천에서 밖으로 나가는 연결만으로 배포했습니다.

  4. 4.
    실패해도 서비스는 살아 있게 약 8초 · 테스트 서버 교체

    포트를 하나씩 교체하고, 응답이 없으면 그 포트만 이전 컨테이너로 되돌립니다.

  5. 5.
    배포 권한은 레포 권한만큼만 Secret 0개 · 베스천 job에 넘기는 값

    운영 서버로 이어지는 베스천 runner의 권한을 배포 스크립트 하나로 좁혔습니다.

  6. 6.
    버전과 릴리스 노트도 자동으로 PR 라벨 · 버전 결정

    PR 라벨로 버전을 정하고, 배포가 끝나면 GitHub Release에 변경 내역을 남깁니다.
