배포 권한은 레포 권한만큼만

운영 서버로 이어지는 베스천 runner의 권한을 배포 스크립트 하나로 좁혔습니다.

Secret 0개베스천 job에 넘기는 값

  1. 01SSR이 꺼져 있던 렌더링
  2. 02페이지뷰가 빠지고 있었다
  3. 03들어갈 수 없는 서버에 배포하기
  4. 04실패해도 서비스는 살아 있게
  5. 05배포 권한은 레포 권한만큼만
  6. 06버전과 릴리스 노트도 자동으로

문제

  • 베스천 runner는 운영 서버로 이어지는 자리라 권한을 최소로 둬야 했다.

해결

  • sudo 없는 전용 계정으로 runner를 돌린다.
  • main · dev workflow만 runner를 쓸 수 있다.
  • runner 키는 authorized_keys의 command=로 배포 스크립트만 실행하고, 인자는 정규식으로 검사한다.
  • 베스천 job에는 Secret을 넘기지 않는다.

결과

  • 사람이 서버에 들어가지 않고 레포 권한만으로 배포된다.
