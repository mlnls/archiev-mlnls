서버 한 대가 얼마까지 버티나

자동 확장 없는 서버 한 대에 단계별 부하를 걸어 처리량 천장과 편한 구간을 확인했습니다.

문제

  • 자동 확장이 없는 버스트형 CPU 서버 한 대로 운영해야 했다.

해결

  • 10명부터 200명까지 단계별 30초씩 부하를 걸었다.
  • 초당 처리량, p50 / 95 / 99, 서버 load · 메모리 · 컨테이너별 CPU를 함께 기록했다.

결과

  • 200명까지 실패 0, 처리량은 초당 약 50에서 평평했다.
  • 편하게 버티는 속도는 분당 1,500 (실패 0 · p95 164ms)
  • 실제 트래픽은 그 수백 분의 1이라 2GB · 월 $12 플랜 그대로 운영에 들어갔다.

메모

  • 리틀의 법칙(L = λ × W)으로 계산한 0.9초가 실측 p50 864ms와 맞았다.
  • 실패 0%가 괜찮다는 뜻은 아니다. Apache는 줄을 세우고, p99 12초는 사용자에게 실패다.
  • 측정 타이밍이 숫자를 속인다. 끝난 뒤 찍은 CPU 0.5%는 거짓이었고, 부하 중에 찍자 70%였다.
