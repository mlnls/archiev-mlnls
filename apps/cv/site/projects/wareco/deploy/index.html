머지하면 출시까지

수자원기술 홈페이지 · 1/5 · 무중단 (reload)

바꿀 수 없는 PHP 레거시에 문법 검사 · 배포 · 무중단 reload · 복구를 붙였습니다.

문제

  • CMS · 문의 · 검색 때문에 정적 사이트로 바꿀 수 없는 PHP 레거시였다.
  • 그 위에 영문판을 새로 열어야 했다.

해결

  • main에 머지하면 바뀐 PHP 파일 문법 검사 → 배포 → Caddy 설정 검사 → 무중단 reload, 실패하면 복구된다.
  • /kor/ 주소는 /eng/로 301 처리했다.

결과

  • 영문판을 출시했고, 이후 수정도 머지 한 번으로 나간다.
