패치가 나오지 않는 PHP 7.4

수자원기술 홈페이지 · 4/5 · 5겹 (완화 4 + 수정 1)

공개 다음 날 나온 원격 코드 실행 취약점을 완화 4겹과 직접 빌드한 패치로 막았습니다.

문제

  • 인증 없이 원격 코드 실행이 가능한 PHP2Shell(CVE-2026-109618 · 109619, CVSS 9.2)이 공개됐다.
  • 공식 이미지는 7.4.33에서 멈춰 기다려도 패치가 없었다.

해결

  • 완화 4겹: Caddy 본문 상한, Apache LimitRequestBody, 파싱 전에 적용되는 php_admin_value, 컨테이너 메모리 1g
  • 수정 1겹: php-config의 원래 빌드 옵션 그대로 백포트 패치를 넣어 다시 빌드했다.
  • 패치 파일은 sha256부터 검사하고, 마커가 없으면 빌드가 실패한다.

결과

  • 요청 최대 크기 210MB → 8MB
  • 방문자는 모르게 CMS 업로드 상한만 200MB → 30MB로 줄였다.

메모

  • ini_set은 본문 파싱 뒤라 늦다. 설정은 무엇보다 “언제” 적용되는지가 중요했다.
  • 백포트는 버전을 올리지 않는다. 버전 문자열 대신 패치가 추가한 설정을 마커로 확인했다.
