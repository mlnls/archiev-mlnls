한 일

수집
채용 플랫폼과 기업 채용 페이지를 매일 아침 모읍니다.
매칭
스킬 · 트랙 · 경력 · 근무지로 점수를 매기고, 마감 · SI/파견 · 학력 · 필수 스택 공백을 근거와 경고로 표시합니다.
맞춤 이력서
Mac 워커가 API 큐에서 일을 가져가 Claude Code로 공고별 Figma 이력서를 만듭니다. spawn으로 실행해 공고 텍스트가 셸 명령이 되는 경로를 막았습니다.
배포
바뀐 앱만 테스트하고 이미지를 만들어, 명령이 제한된 전용 키로 서버에 올립니다. 헬스체크에 실패하면 이전 이미지로 되돌립니다.
운영
같은 서버의 다른 서비스와 Caddy 하나를 나눠 쓰고, 개인 화면은 Tailscale 안에서만 엽니다.

결과

  • 매일 아침 점수 · 근거 · 경고가 붙은 공고 목록과, 공고마다 구성이 달라지는 이력서를 받습니다.

배운 것
