종이로도 나눠 준다

성적 리포트는 화면으로만 보는 게 아니라 종이로 뽑아서 나눠 주기도 했다.
화면에서 멀쩡한 차트가 인쇄하면 배율이 틀어지거나 잘렸다.

인쇄는 화면과 다른 매체다

브라우저는 인쇄할 때 페이지를 새로 배치한다. 화면을 그대로 찍는 게 아니다.

  • 폭이 바뀐다. A4에서 여백 10mm를 빼면 인쇄 폭은 190mm, 약 718px이다. 화면보다 좁다
  • 쪽이 나뉜다. 긴 화면은 아무 데서나 잘려 다음 쪽으로 넘어간다
  • 배경색이 빠진다. 브라우저는 잉크를 아끼려고 배경을 기본으로 인쇄하지 않는다

차트가 잘린 건 첫 번째 때문이었다.
차트는 들어 있는 상자의 폭을 재서 그 크기로 그린다. 인쇄 폭이 좁아지면 넘치는 부분이 잘린다.

인쇄용 규칙을 따로

@media print에 인쇄용 규칙을 따로 두었다.

src/index.css (줄여서 옮김)Text
@media print {
  * { print-color-adjust: exact; }          /* 배경색 · 차트 색을 그대로 */
  @page { size: A4; margin: 10mm; }

  html, body { zoom: 0.95; }               /* 전체를 살짝 줄여 폭에 맞춘다 */
  .print-page { break-after: page; }       /* 덩어리마다 새 쪽에서 시작 */
  .print-page.more-scope { zoom: 0.75; }   /* 분량이 많은 덩어리는 더 줄인다 */
  .hide-on-print { display: none; }        /* 출력 버튼 같은 건 숨긴다 */
}

쪽이 아무 데서나 잘리지 않게, 한 쪽에 들어갈 덩어리를 .print-page로 묶었다.
그리고 덩어리마다 다음 쪽에서 시작하게 했다.
덩어리에 따라 분량이 달라서, 많은 쪽은 zoom을 한 번 더 줄였다.

차트도 잘리던 부분을 하나씩 손봤다.
