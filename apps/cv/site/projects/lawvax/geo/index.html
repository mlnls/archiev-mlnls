AI가 사실을 그대로 가져가게

법무법인 로백스 홈페이지 · 4/5 · 0 → 7종 (구조화 데이터 타입)

법인 · 구성원 · 글을 JSON-LD 그래프로 묶고, 인용하기 좋은 요약과 날짜를 맨 앞에 두었습니다.

문제

  • 구조화 데이터가 없어 검색엔진과 AI가 법인 · 구성원 · 글의 관계를 알 수 없었다.
  • AI가 인용할 때 가져갈 짧고 정확한 문장이 없었다.

해결

  • 법인 · 구성원 · 글을 같은 @id로 연결한 JSON-LD 그래프로 묶었다. 화면에 없는 정보는 채우지 않았다.
  • 업무분야 맨 앞에 두 문장 요약과 <time dateTime>을 두었다.

결과

  • 구조화 데이터 타입 0 → 7종 (LegalService, Person, Service, BreadcrumbList, WebSite 등)

메모

  • GEO는 SEO 위에 “그 페이지가 말하는 사실이 정확한가”가 더해진 일이었다.
