사용자가 관리자 코드까지 받고 있었다

관리자 라우트를 떼어 내 첫 진입 JS에서 쓰지 않는 코드를 걷어냈습니다.

7.2MB → 171KB첫 진입 JS

  1. 01크롤러가 빈 페이지를 보고 있었다
  2. 02옛 주소와 옛 도메인을 한 주소로
  3. 03관리자가 저장하면 바로 반영
  4. 04AI가 사실을 그대로 가져가게
  5. 05사용자가 관리자 코드까지 받고 있었다

문제

  • 관리자와 사용자 코드가 한 번들에 묶여, 첫 진입 JS 대부분이 쓰이지 않는 코드였다 (Coverage로 측정).

해결

  • 관리자 라우트를 React.lazy + Suspense로 나눴다.
  • 루트 배럴 export와 import 경로를 정리해 사용자 번들에 관리자 코드가 섞이지 않게 했다.

결과

  • 첫 진입 JS 7.2MB → 171KB
