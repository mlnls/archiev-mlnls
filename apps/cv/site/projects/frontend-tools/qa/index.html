공통 패키지 결함 12건

사용처에서 하나씩 보고되던 공통 패키지 버그를 모아 고치고 changeset으로 배포했습니다.

12건결함 수정 (MOD-21~35)

  1. 01데스크톱 프로젝트도 명령 하나로
  2. 02앱 프로젝트도 같은 규칙으로
  3. 03배포가 성공했을 때만 릴리즈가 남게
  4. 04릴리즈 노트는 커밋에서
  5. 05쓰지 않는 기능은 걷어내기
  6. 06공통 패키지 결함 12건

문제

  • 사내 서비스가 함께 쓰는 core · basic-ui · utils · hooks에서 버그가 하나씩 보고되고 있었다.

해결

  • 1월 31일에서 다음 달로 가면 3월이 되던 달력, KST에서 달이 밀리던 문제를 고쳤다.
  • SSR에서 SanitizeHtml이 터지던 문제, 이메일 · 생년월일 · 주민번호 정규식 오류를 고쳤다.

결과

  • 결함 12건을 고쳐 changeset으로 배포했다.

메모

  • Release CI에서 npm 11로 만든 lockfile이 Node 20의 npm ci에서 실패했다. npm 10으로 다시 만들어 두 버전 모두 통과시켰다.
