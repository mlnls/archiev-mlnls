배포가 성공했을 때만 릴리즈가 남게

벽촌 FE 공통 모듈 · 사내 CLI · 3/6 · 질문 4개 (bc deploy)

질문 4개로 배포 workflow를 만들고, 배포가 성공해야만 태그 · Release · Slack 알림이 남습니다.

문제

  • 배포 방식이 프로젝트마다 제각각이었다.
  • 릴리즈 노트는 손으로 쓰거나 아예 남지 않아, 지금 운영에 어떤 버전이 떠 있는지 물어봐야 알았다.

해결

  • bc deploy가 질문 4개(Enter면 기본값)로 .github/workflows/deploy.yml을 만든다.
  • 릴리즈 단계는 배포가 성공해야만 이어져, 실패한 배포는 기록되지 않는다.
  • Slack 웹훅은 Secret 이름만 저장한다.
  • 법조인대관에서 먼저 운영한 흐름을 모든 프로젝트로 옮겼다.

결과

  • 최신 Release가 곧 지금 운영 버전이다.

메모

  • 배포 기록은 ‘배포 성공’에 묶어야 믿을 수 있다.
