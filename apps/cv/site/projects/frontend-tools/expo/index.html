벽촌 FE 공통 모듈 · 사내 CLI · 2/6 · + Expo (bc init 선택지)

create-expo-app 위에 사내 설정을 덮고, 앱 정보와 EAS 연결까지 bc init에서 끝냅니다.

문제

  • 앱 프로젝트는 create-expo-app으로 만든 뒤 사내 설정을 매번 손으로 맞췄다.

해결

  • create-expo-app 위에 사내 설정을 덮어씌운다.
  • 앱 이름 · 번들 ID · 딥링크 scheme을 물어 app.config.ts에 적는다.
  • EAS에 로그인돼 있으면 eas init으로 projectId까지 연결한다.
  • NativeWind · TanStack Query · axios를 기본으로 갖춘다.

결과

  • 웹과 같은 API 레이어와 린트 설정으로 앱 프로젝트가 시작된다.
