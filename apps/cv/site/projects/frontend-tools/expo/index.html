앱도 매번 손으로

앱 프로젝트는 create-expo-app으로 만든 다음, 사내 설정을 매번 손으로 맞췄다.

create-expo-app 위에 덮어쓰기

bc init에서 Mobile(Expo)을 고르면, create-expo-app으로 프로젝트를 만든 뒤 그 위에 사내 설정을 덮어씌운다.

  • 앱 이름, 번들 ID, 딥링크 scheme을 물어 app.config.ts에 적는다
  • EAS에 로그인돼 있으면 eas init으로 projectId까지 연결한다
  • NativeWind, TanStack Query, axios를 기본으로 갖춘다

결과

웹과 같은 API 레이어와 린트 설정으로 앱 프로젝트가 시작된다.
