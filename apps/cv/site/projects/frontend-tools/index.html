벽촌 FE 공통 모듈 · 사내 CLI

벽촌 · 2025.09 – 현재 · npm · CLI · GitHub · CLI · npm · settings · GitHub · 공통 패키지

프로젝트가 계속 새로 생기는 SI 환경에서, 명령 하나로 웹 · 앱 · 데스크톱 프로젝트를 같은 구조로 시작하고 배포가 성공하면 릴리즈 노트까지 남도록 사내 CLI와 공통 패키지를 키웠습니다.

역할: Electron · Expo 스타터 · bc deploy · 릴리즈 노트 · v3 정리 · 공통 패키지 QA
기술: Node CLI, Electron, Expo · EAS, GitHub Actions, changesets, pnpm 모노레포

  1. 1.
    데스크톱 프로젝트도 명령 하나로 + Electron · bc init 선택지

    bc init에 Desktop(Electron)을 더해, 보안 기본값과 설치 파일 설정까지 갖춰 시작합니다.

  2. 2.
    앱 프로젝트도 같은 규칙으로 + Expo · bc init 선택지

    create-expo-app 위에 사내 설정을 덮고, 앱 정보와 EAS 연결까지 bc init에서 끝냅니다.

  3. 3.
    배포가 성공했을 때만 릴리즈가 남게 질문 4개 · bc deploy

    질문 4개로 배포 workflow를 만들고, 배포가 성공해야만 태그 · Release · Slack 알림이 남습니다.

  4. 4.
    릴리즈 노트는 커밋에서 날짜 버전 · web@2026.11.05

    공통 settings 패키지에 커밋을 기능 · 수정으로 묶어 노트를 쓰는 명령을 더했습니다.

  5. 5.
    쓰지 않는 기능은 걷어내기 −5,923줄 · 의존성 9개 제거

    아무도 쓰지 않던 채팅과 생성 질문을 지우고, 오래된 CLI로는 실행되지 않게 했습니다.

  6. 6.
    공통 패키지 결함 12건 12건 · 결함 수정 (MOD-21~35)

    사용처에서 하나씩 보고되던 공통 패키지 버그를 모아 고치고 changeset으로 배포했습니다.
