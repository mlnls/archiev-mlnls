문제

  • 데스크톱 요청이 들어와도 CLI는 웹(React · Next)만 만들어, Electron은 매번 손으로 세팅했다.

해결

  • electron-vite로 main · preload · renderer를 나눴다.
  • contextIsolation과 sandbox를 켜고, preload에서 window.api만 노출한다.
  • renderer는 웹과 같은 폴더 구조 · 토큰 · API 레이어를 쓴다.
  • electron-builder로 macOS · Windows 설치 파일을 만든다.

결과

  • Desktop을 고르면 웹 프로젝트와 같은 규칙으로 데스크톱 앱이 시작된다.
