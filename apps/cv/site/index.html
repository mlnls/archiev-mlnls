벽촌 프론트엔드 개발자

2025.06 – 현재

법무법인 로백스 홈페이지

  • CRA 레거시를 Next.js App Router로 옮겨 크롤러가 받는 첫 HTML의 본문을 0자에서 680자로, JS 전송량을 2,512KB에서 251KB로 줄였습니다.
  • 법인·구성원·글을 JSON-LD 그래프로 연결하고 canonical, sitemap, 실제 404, 레거시 주소 21개 패턴의 308 리디렉트를 구성했습니다.
  • 관리자까지 한 번들로 받던 첫 진입 JS를 라우트 단위로 분리해 7.2MB에서 171KB로 줄였습니다.

법률신문 법조인대관

  • SSR을 무력화하던 클라이언트 렌더링 범위를 좁히고 폰트를 dynamic subset으로 바꿔 Lighthouse 성능을 80에서 99로, FCP를 77%, LCP를 73% 개선했습니다.
  • SPA 라우팅에서 누락되던 GA4 추적을 고쳐 월 103만 건 규모의 행동 데이터를 확보했습니다.
  • VPN 뒤 서버의 수동 배포를 베스천 self-hosted runner와 롤링 교체 스크립트로 자동화해, 머지 한 번으로 배포되고 실패하면 자동 복구되게 했습니다.

마켓:D

  • 관리자, 사용자 앱, 웹뷰로 흩어진 레포를 pnpm workspace와 Turborepo 모노레포로 합치고 앱-웹뷰 메시지 타입을 공통 패키지로 묶었습니다.
  • Expo EAS Update를 도입해 웹뷰, 연결 로직, 바이너리로 배포 경로를 나누고 긴급 수정을 스토어 심사 없이 내보낼 수 있게 했습니다.

제주이어드림

  • CloudFormation과 Auto Scaling으로 신청 기간 트래픽 피크에 대응하고, 메인 조회 API에 5분 주기 ISR을 적용했습니다.
  • IP 차단 로직이 Next 서버 자체를 막아 생긴 장애를 x-forwarded-for 전달로 해결했습니다.

경인교대 입법학센터, 엔조이소프트

  • 프론트엔드를 처음부터 끝까지 혼자 구축했습니다.
